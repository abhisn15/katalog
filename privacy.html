Kebijakan Privasi

Cek Dulu ID / Agent Cihuy — alat bantu pembuatan & unggah video afiliasi

Berlaku sejak: 17 September 2026

Agent Cihuy ("aplikasi ini") adalah alat pribadi yang digunakan pemilik channel untuk membuat dan mengunggah video buatannya sendiri ke channel YouTube miliknya sendiri. Aplikasi ini tidak melayani pengguna lain dan tidak mengumpulkan data pribadi orang lain. Halaman ini menjelaskan bagaimana data ditangani, sesuai persyaratan YouTube API Services.

1. Penggunaan YouTube API Services

Aplikasi ini menggunakan YouTube API Services untuk mengunggah video ke channel milik pengguna (pemilik aplikasi) sendiri. Dengan memakai aplikasi ini, Anda juga terikat pada Persyaratan Layanan YouTube. Data ditangani sesuai Kebijakan Privasi Google.

2. Data yang diakses

  • Izin OAuth: hanya youtube.upload — cukup untuk mengunggah video ke channel pemilik. Aplikasi tidak membaca, mengubah, atau menghapus data channel lain.
  • Token akses: disimpan hanya secara lokal di komputer pemilik (file token di folder aplikasi), tidak pernah dikirim ke pihak ketiga atau server mana pun selain Google.
  • Aplikasi tidak mengumpulkan, menyimpan, atau membagikan data pribadi milik penonton atau pengguna lain.

3. Bagaimana data digunakan

Kredensial hanya dipakai untuk satu tujuan: mengunggah video milik pemilik ke channel YouTube-nya sendiri. Tidak ada data yang dijual, disewakan, atau dibagikan ke pihak ketiga. Tidak ada iklan, analitik pihak ketiga, maupun pelacakan.

4. Penyimpanan & keamanan

Token OAuth disimpan lokal di perangkat pemilik dan hanya dipakai oleh pemilik. Tidak ada basis data pengguna, tidak ada server publik yang menyimpan kredensial.

5. Menghapus akses / data

Pemilik dapat mencabut akses kapan saja melalui Google Account → Third-party access, atau dengan menghapus file token lokal. Setelah dicabut, aplikasi tidak lagi dapat mengunggah apa pun.

6. Perubahan kebijakan

Kebijakan ini dapat diperbarui bila diperlukan. Perubahan akan dipublikasikan di halaman ini dengan tanggal berlaku terbaru.
